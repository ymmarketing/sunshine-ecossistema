# Checklist arquitetural

- [x] Cliente como identidade central quando identificável.
- [x] Legado financeiro sem cliente pode existir sem cliente fictício.
- [x] Serviços separados de trabalhos/eventos.
- [x] Consultas e agenda ligadas ao cliente.
- [x] Inscrições de trabalhos ligadas ao cliente e trabalho.
- [x] Pagamentos suportam IMPORT, MANUAL e ASAAS.
- [x] Comissão parametrizada por responsável e beneficiário.
- [x] Filhos da Casa podem reutilizar identidade do cliente.
- [x] Custos/insumos modelados para margem e rentabilidade.
- [x] Reportei separado do financeiro e ligado por campanha/trabalho/período.
- [x] Importação 2026 usa staging e reconciliação.
- [x] RLS e auditoria previstas desde a primeira migração.
- [x] Nenhum segredo ou dado de cliente no GitHub Pages.
